# MindMirror

**A game-based adaptive learning app for children aged 6–12, built for Android and iOS.**

Most digital learning tools ask *what* a child should learn. MindMirror also asks
*how* each child learns best. Children learn through short, calm mini-games while
the app gently adapts difficulty, pace, activity type, and sensory intensity based
on how they interact. Parents and teachers get simple progress insights.

MindMirror is designed with neurodivergent learners in mind, including children
with ADHD or autism, but it is a learning-accessibility tool. It is not a medical,
diagnostic, or therapeutic product and makes no clinical claims.

## Mini-games
- **Focus Forest**: sustained and selective attention
- **Memory Island**: working memory and sequencing
- **Emotion Explorer**: emotional vocabulary and recognition
- **Puzzle Workshop**: logical and spatial reasoning
- **Calm Cove**: optional calming, self-regulation activities
- **Story Builder**: creativity and flexible language
- **Everyday Adventures**: routines and independence
- **Social Story Studio**: communication and perspective-taking

## Principles
- **Offline-first:** core gameplay works without internet or AI
- **Privacy-first:** parent-managed profiles, no camera or biometric data, no unnecessary personal data
- **Gentle by design:** no leaderboards, no punishment, no comparison between children
- **Transparent adaptation:** difficulty changes are bounded, reversible, and manually adjustable
- **Accessible:** adjustable text size, reduced motion, large touch targets, replayable instructions
- **Age-aware:** separate presentation modes for ages 6–8 and 9–12
